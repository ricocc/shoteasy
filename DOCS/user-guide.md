# 用户功能指南

## 更换图片

图片导入后仍可随时更换：

- 编辑状态下，点击顶部的“更换图片”按钮选择新文件。
- 也可以把 JPEG、PNG、BMP、GIF 或 WebP 文件拖到整个编辑画布，释放后直接替换当前图片。
- 替换图片会清除旧图片上的标注，但保留画布尺寸、背景和外框等设置。
- 尚未开始编辑时，欢迎页的整个工作区域都可以接收图片；中间上传卡片仍支持点击选择文件。

## 导入图片

初始页支持：

- 点击或拖放 JPEG、PNG、BMP、GIF、WebP 文件。
- 从剪贴板粘贴第一张受支持的图片。
- 点击相机按钮并授权浏览器进行屏幕捕获。
- 点击内置示例快速体验。

当前界面不提供文本美化、代码美化和 GIF 入口；相关能力尚未实现。

## 画布尺寸

默认使用 `Auto`：图片导入或裁剪后，画布在图片四周增加约为图片短边 15% 的空间。也可以输入自定义宽高，或选择以下预设：

- 常见比例：16:9、3:2、4:3、5:4、1:1、4:5、3:4、2:3、9:16。
- Instagram：Post、Portrait、Story（代码中标题目前拼写为 `Stroy`）。
- X：Tweet、Cover。
- YouTube：Banner、Thumbnail、Video。
- Pinterest：Long、Optimal、Square。

## 图片与背景设置

右侧栏可调整：

- 裁剪、水平翻转、垂直翻转。
- 图片在画布中的九宫格位置。
- 整体缩放（0.1–3）。
- 留白（0–60）和留白颜色。
- 圆角（0–20）和阴影（0–6）。
- 常用背景、更多纯色/渐变/远程图片背景，以及自定义纯色。

远程图片背景依赖 Unsplash 网络资源。网络或跨域限制可能导致背景无法显示或导出。

## 外框

可选外框包括：

- 无外框、浅色描边、深色描边。
- macOS 浅色/深色标题栏。
- Windows 浅色/深色标题栏。
- MacBook Pro 16、MacBook Air、iMac Pro、iPad Pro、iPhone Pro 设备框。

设备框提供 Cover、Contain、Stretch 三种适配选项。普通图片和浏览器标题栏固定使用 Cover。

## 标注工具

顶部工具栏提供空心矩形、实心矩形、圆形、直线、箭头、画笔、放大镜、步骤编号和 Emoji。颜色与线宽会作为新标注默认值；若已有标注被选中，修改颜色或线宽也会作用于选中项。

- 拖动创建大部分图形。
- 步骤编号单击创建，数字取当前最大编号加一。
- Emoji 从选择器插入到画布中心。
- 画笔保持启用，可连续绘制；其他工具完成一次绘制后自动退出。
- 手形按钮切换画布拖动模式。
- `Backspace` / `Delete` 删除选中标注。

撤销/重做尚未启用。

## 水印与 HDR

文字水印支持内容、颜色、±45° 方向。默认覆盖整张成品；启用 “Only Background” 后，水印位于截图下方，只在背景区域显现。

HDR 是浏览器 Canvas 滤镜组合：提高饱和度、对比度和亮度并叠加 screen 效果。它不是高动态范围文件格式转换，处理大图时会增加内存和计算开销。

## 缩放与导出

画布右下角可放大、缩小、选择 50%/100%/150%/200%，或适应可用空间。这只影响编辑视图，不改变最终画布尺寸。

导出设置支持：

- 格式：PNG、JPG、WebP。
- 像素倍率：1x、2x、3x。
- 下载或复制到剪贴板（复制固定为 PNG）。

快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Cmd/Ctrl + S` | 按当前设置下载 |
| `Cmd/Ctrl + C` | 复制 PNG |
| `Cmd/Ctrl + -` | 缩小画布视图 |
| `Cmd/Ctrl + =` | 放大画布视图 |
| `Cmd/Ctrl + 0` | 适应可用空间 |
| `Backspace` / `Delete` | 删除选中标注 |

复制与屏幕捕获需要受支持的浏览器、HTTPS/localhost 环境及用户授权。
