# V1 验收标准

## 使用方式

本项目 V1 不增加自动化测试框架。本清单必须在 M0 记录当前基线，在每个里程碑验证受影响部分，并在 M7 完整执行。

验收结果使用：通过、失败、不适用、无法验证。失败和无法验证必须记录环境、步骤、实际结果和后续处理，不得省略。

## 阻断规则

以下情况阻止进入下一里程碑或发布：

- 无法安装依赖或站点/库构建失败。
- 旧功能入口丢失或导出结果明显变化。
- 项目状态与画布状态不一致。
- Undo/redo 恢复错误作品或造成崩溃。
- PNG/JPG/WebP 导出不可用或尺寸错误。
- npm 组件旧导入方式失效。
- 草稿覆盖宿主传入的 defaultImg。
- 区域效果导出位置与预览明显不一致。

## 导出矩阵

以下组合至少分别测试一次普通背景、新图片背景、新外框和区域效果：

| 格式 | 1x | 2x | 3x | 透明/填充要求 |
| --- | --- | --- | --- | --- |
| PNG | 必测 | 必测 | 必测 | 无背景时允许透明 |
| JPG | 必测 | 抽查 | 抽查 | 透明区域填白 |
| WebP | 必测 | 抽查 | 抽查 | 当前实现保持白底策略 |

最终像素宽高必须等于逻辑画布尺寸乘像素倍率。复制固定使用 PNG，并验证 Clipboard API 权限失败提示。
