# V1 产品规格

## 产品定位

RicoScreenshot V1 是一个本地优先、无需登录的单图截图美化工具。用户通过文件选择、拖放、粘贴或现有系统截屏能力导入图片，完成画布尺寸、背景、外框、图片样式和标注编辑，再在浏览器内导出图片。

V1 的竞争力来自“打开即用、功能集中、包体和架构相对轻量”，而不是功能数量或完整设计平台能力。

## 目标用户与核心任务

主要用户：

- 需要快速制作产品截图、教程配图或社交媒体图片的独立开发者和内容创作者。
- 需要在 React 产品中嵌入截图美化能力的 `ImageBeautifier` 组件使用者。
- 希望图片尽量留在本地浏览器、不依赖账户系统的用户。

核心任务：

1. 快速导入或粘贴一张图片。
2. 用比例、背景、外框和预设快速得到可用版式。
3. 用文字、箭头、步骤、模糊等工具解释或隐藏局部内容。
4. 可靠撤销误操作，刷新页面后可恢复独立站草稿。
5. 按需要的格式和清晰度下载或复制成品。

## 成功标准

- 已有导入、编辑、设备框、水印、HDR、复制和导出能力不发生功能回退。
- 桌面端高频操作不需要在一个长侧栏中反复滚动。
- 用户可通过左侧三个入口完成比例、外框和布局选择。
- 用户可通过底部工具栏完成全部标注操作。
- 用户可通过右侧属性栏完成背景与当前图片样式调整。
- 所有业务编辑操作可以撤销和重做。
- 独立站刷新后能够自动恢复最近草稿；组件默认不读写宿主本地草稿。
- PNG/JPG/WebP 和 1x/2x/3x 导出结果与画布预览一致。

## 信息架构

### 顶部全局栏

从左到右：

1. 品牌或宿主提供的 `headLeft`。
2. 换图、清空。
3. 撤销、重做及禁用状态。
4. 弹性占位。
5. 主题切换或宿主提供的 `headRight`。
6. 复制。
7. 导出主按钮与格式/倍率设置。

导出入口必须始终可见，不再放在右侧滚动区域底部。

### 左侧结构栏

左侧使用三个纵向卡片/折叠入口：

- 比例：Auto、常见比例、社交平台预设、搜索、自定义宽高。
- 外框：无、描边、浏览器标题栏、设备框和新增轻量外框。
- 主截图直接操作：选中、抓手拖动、中心旋转和关闭。

左侧调整的是作品结构，不放颜色、阴影、水印等细节属性。

### 中央视图

- LeaferJS 画布占据最大可用空间。
- 保留当前点阵工作区视觉，但重做为深色中性背景。
- 右下角保留放大、缩小、百分比和适应画布。
- 视图缩放不改变最终导出尺寸，也不进入撤销历史。

### 底部标注工具栏

工具顺序：

1. 选择。
2. 拖动画布。
3. 空心矩形。
4. 实心矩形。
5. 圆形。
6. 直线。
7. 箭头。
8. 画笔。
9. 文字。
10. 模糊。
11. 马赛克。
12. 聚光。
13. 放大镜。
14. 步骤编号。
15. Emoji。

颜色、线宽或文字样式作为上下文控件显示；未选中相关工具或对象时不占用主工具栏空间。

### 右侧属性栏

右侧按以下顺序组织折叠分组：

1. 背景：类型、预设、上传、填充方式、位置、模糊、遮罩、噪点。
2. 图片：裁剪、翻转、九宫格位置、缩放、旋转、留白和留白颜色。
3. 边框与阴影：圆角、描边、阴影强度。
4. 水印与 HDR：保留现有能力和语义。

选中文字或区域效果时，右侧顶部临时显示对应对象属性；取消选择后恢复作品属性。

## 响应式行为

### 桌面端

- 顶部栏固定高度约 56px。
- 左栏建议宽度 220–240px。
- 右栏建议宽度 300–340px。
- 中央画布弹性占满剩余区域。
- 底部工具栏悬浮于画布内部，不遮挡右下角缩放控件。

### 平板与手机

- 中央视图优先占满可用区域。
- 左侧结构栏通过左侧抽屉打开。
- 右侧属性栏通过右侧抽屉或底部面板打开。
- 标注工具栏允许横向滚动，不缩小到无法触控。
- 导出仍保留在顶部；空间不足时只显示图标和简短主操作。
- 不要求移动端文字双击编辑，必须能通过属性面板修改文字内容。

## 比例与布局

### 比例

保留当前尺寸预设及 Auto 逻辑。新增搜索只搜索本地配置，不请求网络。自定义宽高必须大于 0，提交后形成一次可撤销操作。

### 主截图直接操作

- 点击主截图显示蓝色选中边框、顶部中心旋转控制点和关闭按钮；四角控制点可拖拽缩放，边中点不启用。浏览器外框下缩放网页内容和外框宽度，但顶部栏高度只由左侧“顶部尺寸”控制。
- 截图主体支持 `grab`/`grabbing` 拖动，移动和旋转同时作用于截图、浏览器/设备外框、圆角和阴影，背景及独立标注保持不变。
- 位置以当前九宫格对齐为基准，拖动写入 `offsetX`/`offsetY`；重新点击九宫格后清零偏移。旋转使用现有 `rotation`，与右侧旋转滑杆双向同步。
- 拖动或旋转释放时只提交一条历史记录；关闭按钮清除图片和标注但保留背景、尺寸和外框配置。旧草稿缺少偏移字段时按 0 兼容。

## 外框范围

必须保留：无、浅色/深色描边、兼容旧文档 ID 的浏览器标题栏和现有设备框。

新增：

- Card：图片外增加独立卡片衬底。
- Stack：后方一层轻微偏移卡片。
- Stack 2：后方两层不同偏移卡片。
- Glass Light / Glass Dark：半透明玻璃衬底和轻描边。
- Arc 风格：只借鉴简洁浏览器标题栏结构，不复制商标、Logo 或专有素材。
- Polaroid：白色相纸式边框，下边距更宽。

新增外框必须使用项目自有 LeaferJS 图形或项目资源实现。

浏览器外框提供 Safari/Chrome 明暗四种结构化样式和 Arc 简洁样式。用户可填写地址栏 URL，并在 50%–200% 范围调整浏览器顶部尺寸，默认 100%；100% 对应清晰可读的放大基准。两项配置必须进入项目文档、撤销/重做、草稿和导出。URL 只作为作品中的展示文字，不发起网络请求或网页抓取。

## 背景范围

类型：无、纯色、渐变、内置图片、上传图片。

内置图片沿用配置驱动方式，按推荐、抽象、自然、桌面分类。V1 不提供网络搜索。远程图片不可用时应提示错误并保留上一个有效背景。

图片背景属性：Cover、Contain、Stretch，九宫格位置，模糊，颜色遮罩及透明度，噪点强度。

## 文字与区域效果

### 文字

支持内容、字号、常规/粗体、文字颜色、左/中/右对齐、背景色、内边距和圆角。支持多行。桌面端可双击进入文字编辑；所有平台均可通过属性面板编辑。

V1 不做字体市场、字体上传、复杂字距/行高、文字描边、弧形文字或文本模板。

### 模糊与马赛克

用户拖出矩形区域后可以移动、缩放和删除。效果只处理底图快照，不递归处理其他标注。模糊和马赛克强度可在合理范围内调整。

### 聚光

聚光由覆盖整张画布的半透明遮罩和一个可移动缩放的透明区域组成。V1 支持矩形圆角聚光区域，不增加自由路径聚光。

## 原有能力保护

以下行为必须原样保留：

- 文件选择、拖放、粘贴、现有系统截屏和示例图片。
- 自动尺寸、所有现有尺寸预设和自定义尺寸。
- 裁剪、水平/垂直翻转、位置、缩放、留白、圆角和阴影。
- 当前所有背景配置与设备资源。
- 当前所有标注、选择、变形和删除。
- 水印前景/仅背景和 HDR。
- PNG/JPG/WebP、1x/2x/3x、下载和复制。
- 当前快捷键语义。
- `headLeft`、`headRight`、`defaultImg`、`isDark`、`boxClassName` 和 `onClear`。
